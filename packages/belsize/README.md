# @x-govuk-ui/belsize

`@x-govuk-ui/belsize` adds Tiles to [x-govuk-ui](https://x-govuk-ui.org/), built on react-mosaic.

## Install

Install it with `x-govuk-ui`, at the same version:

```sh
npm install x-govuk-ui @x-govuk-ui/belsize
```

## Usage

Import its stylesheet after x-govuk-ui's:

```tsx
import "x-govuk-ui/styles.css";
import "@x-govuk-ui/belsize/styles.css";
import { Tile, Tiles } from "@x-govuk-ui/belsize";
```
