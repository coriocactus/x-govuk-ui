# People's names in the examples

The examples name people after UK prime ministers. Each person appears once across the workbench, so no two examples share a name. Names are given from the latest prime minister to the earliest, in the order the components appear in the sidebar. A new example takes the next unused name, and this list records it. When a new prime minister takes office, every name moves one place down the list, so the latest comes first.
