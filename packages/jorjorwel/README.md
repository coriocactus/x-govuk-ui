# @x-govuk-ui/jorjorwel

`@x-govuk-ui/jorjorwel` adds a rich text editor to [x-govuk-ui](https://x-govuk-ui.org/), built on Lexical.

## Install

Install it with `x-govuk-ui`, at the same version:

```sh
npm install x-govuk-ui @x-govuk-ui/jorjorwel
```

## Usage

Import its stylesheet after x-govuk-ui's:

```tsx
import "x-govuk-ui/styles.css";
import "@x-govuk-ui/jorjorwel/styles.css";
import { Editor } from "@x-govuk-ui/jorjorwel";
```
