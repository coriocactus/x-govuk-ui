# @x-govuk-ui/memetics

`@x-govuk-ui/memetics` adds charts to [x-govuk-ui](https://x-govuk-ui.org/), built on Recharts.

## Install

Install it with `x-govuk-ui`, at the same version:

```sh
npm install x-govuk-ui @x-govuk-ui/memetics
```

## Usage

Import its stylesheet after x-govuk-ui's:

```tsx
import "x-govuk-ui/styles.css";
import "@x-govuk-ui/memetics/styles.css";
import { Chart } from "@x-govuk-ui/memetics";
```

## Other packages

`@x-govuk-ui/memetics` is released with four other packages, at the same version:

- [`x-govuk-ui`](https://www.npmjs.com/package/x-govuk-ui), the library
- [`@x-govuk-ui/jorjorwel`](https://www.npmjs.com/package/@x-govuk-ui/jorjorwel), the Editor, on Lexical
- [`@x-govuk-ui/belsize`](https://www.npmjs.com/package/@x-govuk-ui/belsize), Tiles, on react-mosaic
- [`@x-govuk-ui/mcp`](https://www.npmjs.com/package/@x-govuk-ui/mcp), an MCP server that answers an agent's questions about the components
